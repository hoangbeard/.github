# .github

Default community health files for repositories owned by [@hoangbeard](https://github.com/hoangbeard).

GitHub uses these files in any of my repositories that does not have its own copy.

| File | What it is for |
|---|---|
| [SECURITY.md](SECURITY.md) | How to report a vulnerability |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to suggest a change |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | How we treat each other |
| [SUPPORT.md](SUPPORT.md) | Where to ask a question |
| [Issue templates](.github/ISSUE_TEMPLATE) | Bug reports and feature requests |
| [Pull request template](.github/pull_request_template.md) | A short checklist for every pull request |
