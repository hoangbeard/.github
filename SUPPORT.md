# Getting help

- **Question about a project:** use the repository's Discussions tab if it is
  turned on. If not, open an issue and start the title with `Question:`.
- **Bug:** open an issue using the bug report template.
- **Security issue:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

These are personal projects, maintained on a best-effort basis.
Replies may take a few days.
