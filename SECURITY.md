# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue.

Report it privately instead: open the repository's **Security** tab and click
**Report a vulnerability**. This uses GitHub's private vulnerability reporting.

Please include:

- What you found and where (file, line, or URL)
- Steps to reproduce it
- What an attacker could do with it

You can expect an acknowledgement within 5 business days. These are personal
projects maintained on a best-effort basis. There is no bug bounty.

## Scope

Example credentials, keys and tokens in these repositories are placeholders or
intentionally fake training data. If you find something that looks real,
please report it as above.
